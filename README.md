Supplementary materials

This repository provides the supplementary material for the paper: "Performance analysis of Multi-RIS-assisted UAV relay networks with hardware impairments and mixed phase shift".

The corresponding PDF contains additional derivations, comparison experiments, model extension and validations that support the revised manuscript. The detailed content is as following:


Part I: COMPARISON EXPERIMENT AND EXTENSION

(a) Our model versus “directly using UAV relays”; pp. 1--2

(b) Our model Comparing with “using cascaded cooperative RISs”; pp. 2--4

(c) Detailed extension of using active RIS; pp. 4--6

(d) Influence of imperfect CSI environment; pp. 6--7

Part II: INVESTIGATION OF MODELING METHODOLOGY

(a) Accuracy of using Laguerre-polynomial expansion? pp. 7--8

(b) Does Central Limit Theorem repeatedly used and How about the accuracy for relatively small N? pp. 9--10

(c) Impact of synchronization and phase alignment among multiple distributed UAV mounted RISs; pp. 10--12

(d) Accuracy influence for using Gaussian quadrature method; pp. 12--13

(e) Whether the closest association policy is always better? pp. 13--16
